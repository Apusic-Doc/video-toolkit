特性

为规模化视频制作而生

每个环节都可独立运行，也能串联成全自动流水线。一套工具，中英双语，批量出品。

01 / whisper

语音识别 → 字幕

Whisper 提取录屏中的语音，生成毫秒级时间戳的 SRT 字幕。支持 faster-whisper 加速，small 模型精准高效。

02 / edge-tts

AI 神经语音配音

微软神经 TTS，中文 Xiaoxiao / 英文 Ava，自然度逼近真人。自动对齐原始语速，画面与声音完美同步。

03 / deepseek

字幕翻译 → 多语言

DeepSeek API 自动翻译中文字幕为英文，一键生成英文版演示视频。保留原始时间轴，字幕与配音全替换。

04 / ffmpeg

音视频合成

替换原始音频为 AI 配音，烧录字幕到视频。支持 atempo 调速、多段拼接，输出 H.264 MP4 成片。

05 / modular

模块化管道

字幕提取、AI 配音、视频合成各自独立。可单独运行某一步，也可串联全自动。灵活的后期工作流。

06 / status

状态管理

一键查看全部 feature 的录制和出片进度。管理数十个演示视频的制作状态，批量掌控。

流程

一条命令穿透全流程

每一步都可拆解、可替换、可跳过。完全掌控后期制作。

快速开始

两分钟上手

安装

# 克隆仓库
git clone https://github.com/Apusic-Doc/video-toolkit.git
cd video-toolkit

# 安装依赖
brew install ffmpeg
pip3 install faster-whisper
# edge-tts 已预配在 .venv/ 中

使用

# 1. Mac Cmd+Shift+5 录制屏幕 + 自然讲解
# 保存到 feature 目录: recording.mov

# 2. 一键出片
./video-toolkit.sh all 05

# 3. 调整字幕后重新合成
./video-toolkit.sh dub 05  # AI 配音（试听）
./video-toolkit.sh mix 05  # 合成视频
命令

完整命令列表

命令说明依赖

srt 05仅提取字幕whisper
dub 05仅生成 AI 配音（试听）edge-tts
mix 05仅合成视频ffmpeg
trans 05翻译字幕: 中文 → 英文DeepSeek API
en 05英文全流程whisper + DeepSeek + edge-tts

mix-en 05仅合成英文视频ffmpeg
status 05查看单个功能状态—
status --all查看全部功能状态—
