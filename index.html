Video Toolkit

从原始录屏到多语言成片，一键完成。
Whisper 语音识别 · 微软神经 TTS · DeepSeek 翻译 · ffmpeg 合成

🚀 快速开始 ⭐ GitHub

✨ 核心功能

🎙️

语音识别

Whisper 自动提取录屏中的语音，生成带毫秒级时间戳的 SRT 字幕

🤖

AI 配音

微软神经语音 edge-tts，中文/英文自然度接近真人，替换原声毫无违和感

🌐

多语言

DeepSeek API 自动翻译字幕，一键生成英文版演示视频，字幕 + 配音全替换

🔧

模块化

字幕提取、AI 配音、视频合成各自独立，灵活编排，适应各种后期工作流

⚡

语速对齐

自动检测 AI 配音与原始语音的时差，通过 atempo 精准调速，画面与声音完美同步

📊

状态管理

一键查看所有功能的录制和出片进度，批量管理多个演示视频的制作状态

🚀 快速开始

安装

# 克隆仓库
git clone https://github.com/Apusic-Doc/video-toolkit.git
cd video-toolkit

# 安装依赖
brew install ffmpeg
pip3 install faster-whisper
# edge-tts 已预配在 .venv/ 中

使用

# 1. Mac Cmd+Shift+5 录制屏幕 + 自然讲解
# 保存到 feature 目录: recording.mov

# 2. 一键出片
./video-toolkit.sh all 05

# 3. 调整字幕后重新合成
./video-toolkit.sh dub 05 # 重生成 AI 配音（试听）
./video-toolkit.sh mix 05 # 合成最终视频

📋 命令一览

命令说明依赖
all 05全流程: 字幕 → AI配音 → 合成ffmpeg + whisper
srt 05仅提取字幕whisper
dub 05仅生成 AI 配音（试听）edge-tts / say
mix 05仅合成视频ffmpeg
trans 05翻译字幕: 中文 → 英文DeepSeek API
en 05英文全流程whisper + DeepSeek + edge-tts
dub-en 05仅生成英文配音edge-tts
mix-en 05仅合成英文视频ffmpeg
status 05查看单个功能状态—
status --all查看全部功能状态—
