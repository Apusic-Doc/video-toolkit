特性

为规模化视频制作而生

每个环节都可独立运行，也能串联成全自动流水线。一套工具，中英双语，批量出品。

01 / whisper

语音识别 → 字幕

Whisper 提取录屏中的语音，生成毫秒级时间戳的 SRT 字幕。支持 faster-whisper 加速，small 模型精准高效。

02 / edge-tts

AI 神经语音配音

微软神经 TTS，中文 Xiaoxiao / 英文 Ava，自然度逼近真人。自动对齐原始语速，画面与声音完美同步。

03 / deepseek

字幕翻译 → 多语言

DeepSeek API 自动翻译中文字幕为英文，一键生成英文版演示视频。保留原始时间轴，字幕与配音全替换。

04 / ffmpeg

音视频合成

替换原始音频为 AI 配音，烧录字幕到视频。支持 atempo 调速、多段拼接，输出 H.264 MP4 成片。

05 / slideshow

幻灯片生成

截图 + 解说文字 → 自动配音合成视频。支持 meta.json 三级配置，封面/BGM/封底。

06 / config

meta.json 配置

项目/Feature/单页三级合并，voice/bgm/cover/outro 灵活覆盖。无配置文件完全向后兼容。

07 / vt ui ⭐

可视化管理台

网页里改封面/字体/语音/字幕，字体点开真实渲染放大预览，语音点击直接试听。任务面板实时日志，配音/成片直接在线听/看，不用等整条视频合成完。

08 / libass

字幕硬烧录

真烧进画面像素，不是外挂 .srt——字体/字号/颜色/描边/位置全部可配。配音手工偏移 dub_offset 微调整体快慢，字幕自动跟着同步。

09 / codegen

Codegen 选择器草稿

vt codegen 打开中文界面的 Playwright codegen 窗口，手动走一遍操作路径即可生成选择器草稿 nav-draft.spec.js；把草稿交给 AI，vt sync 会提示 AI 把精确选择器合并进 record.spec.js 并更新 timeline.json，不用手抄。

10 / ImageMagick

封面/片头生成

ImageMagick 按 meta.json 里的 title/subtitle/company/logo/cover_accent_color 直接画出片头图，再编码成与正文同一套编码参数的片段，可无损拼接。vt cover 单独预览效果，不用跑完整条流水线。

幻灯片

截图+解说→演示视频

放入截图和一段解说文字，自动配音合成幻灯片视频。支持 meta.json 三级配置 (voice/bgm/cover/outro)。

目录结构

feature-02-slides/
  └── slides/
      ├── 001-overview.png
      ├── 002-features.png
      ├── ...
      └── narration.txt  ← one line per slide

解说模式

支持三种解说文本配置，灵活适配不同场景

# A: narration.txt — one line per slide (simplest)
# line 1 → slide 1, line 2 → slide 2

# B: paired .txt — one txt per image
# 001-overview.png + 001-overview.txt

# C: meta.json — inline text + advanced config
{ "pages": [{ "image": "01.png", "text": "script", "voice": "en-US-AvaNeural" }] }

快速开始

两分钟上手

1. 配置

# 设置 DeepSeek Key（翻译功能）
vt config DEEPSEEK_API_KEY=sk-xxx
# 查看全部配置
vt config

2. 目录结构

按 feature-XX-name/ 格式创建目录，放入录屏文件 recording.mov

feature-01-ipv6-http2-websocket/
└── recording.mov  ← 你的录屏

3. 运行

feature 参数支持三种写法：编号 01 / 全名 feature-01-ipv6-http2-websocket / 路径

# Record (Cmd+Shift+5) → recording.mov

# One command to final cut
vt all 01

# Adjust subtitles then
vt dub 01  # AI dub
vt mix 01  # compose
配置

配置文件

全局 CLI 默认值存储在 ~/.config/video-toolkit/config，不受 git 管理。通过 vt config 命令读写。

配置项默认值说明
DEEPSEEK_API_KEY—DeepSeek API Key（翻译功能）
VIDEO_ASRfaster-whisperASR 引擎: faster-whisper / openai-whisper / funasr
VIDEO_VOICEzh-CN-XiaoxiaoNeural中文 AI 配音语音
VIDEO_VOICE_ENen-US-AvaNeural英文 AI 配音语音
VIDEO_BURN_SUB0字幕烧录开关 (0=关闭 1=开启)

字幕的字体/字号/颜色/描边/位置不是全局 CLI 配置，而是 meta.json 里的 subtitle_style 对象（font_name/font_size/color/outline/margin_v），走项目级/功能级三级合并——项目根目录的 meta.json 统一定好，个别功能点才需要单独覆盖。

常见问题

⚠️ "Warning: You are sending unauthenticated requests to the HF Hub"

Whisper 模型托管在 HuggingFace，不影响功能，只下载一次后缓存。可设 export HF_TOKEN=hf_xxx 提速。

🔧 faster-whisper / edge-tts 不可用

pip3 install faster-whisper 或 python3 -m venv .venv && .venv/bin/pip install edge-tts

🎯 中文识别不够准确

设置 vt config VIDEO_ASR=funasr 切换 SenseVoice，或编辑 video-toolkit.sh 将 Whisper 模型从 small 改为 medium。

🔑 DeepSeek API Key 配置

vt config DEEPSEEK_API_KEY=sk-xxx

▶️ 如何试听 AI 配音？

vt play 01 dub

🔥 vt burn 报错找不到 ffmpeg-full

标准 Homebrew ffmpeg 不含 libass，无法硬烧字幕。安装 brew install ffmpeg-full 即可，它是 keg-only，不会覆盖默认 ffmpeg。

⏱️ 配音和画面/字幕不同步

在 vt ui 或 meta.json 里设置 dub_offset（秒，可负数，负数=配音提前）微调，然后 vt redub 01 && vt burn 01 重新生成，字幕会跟着配音一起偏移。

🖥️ vt ui 打不开 / 页面报错找不到某个模块

多半是前端缓存的旧构建。清理后重开: rm -rf ~/.local/share/video-toolkit/ui-client/{node_modules,dist} && vt ui，会自动重新安装依赖并构建。
